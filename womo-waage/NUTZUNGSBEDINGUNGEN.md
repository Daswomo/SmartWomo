## 1. Geltungsbereich

Diese Bedingungen gelten für die Firmware und alle Dateien der SmartWomoHA-Projekte, z. B.
**SmartWomo Truma**, **Womo-Gaswaage** und **SmartWomo-Dimmer** (im Folgenden „Software“),
samt Anleitungen, Schaltplänen, Videos und Beispielen.
Wer die Software herunterlädt, aufspielt oder benutzt, erkennt diese Bedingungen an.

## 2. Was du bekommst – und was nicht

- Die Software wird **kostenlos** zur Verfügung gestellt.
- **Hardware ist nicht enthalten.** ESP32-Boards, M5Stack-Teile, Wägezellen, LIN-Transceiver,
  Kabel, Gehäuse, Netzteile usw. **kaufst du selbst** bei einem Händler deiner Wahl.
- **Aufbau, Verdrahtung und Einbau machst du selbst** und in eigener Verantwortung.
  Es wird keine Hardware verkauft, montiert oder eingebaut.
- Freiwillige Spenden sind willkommen, sind aber **kein Kaufpreis** und begründen keinen Anspruch
  auf Leistungen, Updates oder Unterstützung.

## 3. Kostenlose Freischaltung

- Jedes Gerät zeigt eine Freischaltung mit 8-stelligem Code. **Die Freischaltung ist kostenlos.**
- Sie dient nur dazu, dass ich weiß, **wer die Software nutzt**. Dafür schickst du mir deinen Namen und die
  MAC-Adresse des Geräts (steht im Setup) und bekommst den Code zurück.
- Ohne Code lässt sich die Software installieren und verbinden, aber **nichts steuern**
  (bei der Gaswaage: keine Werte). Erst mit dem Code ist alles nutzbar.
- Wer damit nicht einverstanden ist, nutzt die Software bitte nicht.

## 4. Keine Gewährleistung

Die Software wird so bereitgestellt, **wie sie ist**. Es gibt keine Zusage, dass sie fehlerfrei ist,
ohne Unterbrechung läuft, mit bestimmten Geräten (z. B. bestimmten Heizungs-, Klima- oder CP-Plus-Versionen)
funktioniert oder für einen bestimmten Zweck geeignet ist.
Ein Anspruch auf Fehlerbehebung, Updates oder neue Funktionen besteht nicht.

## 6. Sicherheit – bitte lesen

- Die Software ersetzt **keine Sicherheitseinrichtung**. Die Gaswaage ist **kein Gaswarner**;

- Arbeiten an **Gasanlage, 230 V und Fahrzeugelektrik** nur, wenn du sie fachgerecht ausführen kannst –
  im Zweifel von einer Fachkraft. Für Einbauten im Gaskasten gelten die Vorgaben deines Gasprüfers

  berühren. Das klärst du selbst mit dem Hersteller.
- Eine Steuerung aus der Ferne (App, Home Assistant, MQTT) kann Geräte einschalten, während niemand vor Ort ist.
  Sichere dein Netzwerk und deine Zugänge ab.
